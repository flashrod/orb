A browser that feels
like yours.

Orb is an Arc-inspired browser for focus and privacy. Spaces, Boosts, real ad + tracker blocking — wrapped in a warm monochrome UI you can restyle completely. Built for macOS, Apple Silicon first.

Join the waitlist View on GitHub

Built for focus, not distraction

Everything Orb does, it does transparently. No hidden telemetry, no dark patterns.

Spaces

Named, color-coded spaces that isolate your tabs, bookmarks, and browsing context. Work, personal, research — never mixed.

Boosts

Per-site custom CSS and JS with an intelligent element picker. Hide cookie banners, clean up news sites, reshape the web to your taste.

Real privacy

EasyList + uBlock filtering, third-party cookie blocking, fingerprinting protection, HTTPS-only mode. Default-deny permissions. Nothing phones home.

Privacy that isn’t slop

Most browsers treat privacy as a toggle. Orb treats it as the default. Ad and tracker blocking use real EasyList/uBlock rule parsing — not a list of hardcoded domains. Third-party cookies are blocked. Fingerprinting headers are stripped. HTTPS upgrades happen automatically. You get a blocked-request log and granular allowlists so you see exactly what was stopped and why.

Ad + tracker blocking

EasyList, uBlock Origin, EasyPrivacy, CookieMonster — compiled filter rules with cosmetic filtering.

Third-party cookies

Blocked by default with per-site exceptions and a one-click "this site is broken" toggle.

Fingerprinting defense

Client-hint header stripping and consistent low-entropy values so you don’t stand out.

HTTPS-only mode

Automatic HTTP → HTTPS upgrades with clean fallbacks and per-site exceptions.
